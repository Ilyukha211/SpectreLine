# SpectreLine

SpectreLine is a system inspection and auditing tool designed for Windows. It provides a clean interface to examine file structures, check application shortcuts, monitor processes, and review local system data.

## Features

* Drive and file structure scanner
* Windows shortcut (.lnk) target inspector
* Local Steam account detector
* Active process monitoring and management
* Quick access to administrative utilities

## Installation and Usage

1. Go to the [Releases](https://github.com/Ilyukha211/SpectreLine/releases) page.
2. Download the latest executable file (`SpectreLine-v1.0.exe`).
3. Run the application directly. No installation or Python is required.

If Windows SmartScreen shows a warning, click **More info** → **Run anyway**. The application is not digitally signed.
